# Assignment evidence map

The current team naming decision is Wearabouts. This document uses Wearabouts in prose, while a few internal CSS and storage identifiers retain the older Drape prefix for compatibility. The AGENTS.md naming edit awaits exact-text approval.

This is an evidence checklist for the 20 compulsory milestones and the compulsory ungraded problem statement. "Implemented evidence" means the repository contains a relevant route, component, schema or document. It does not prove that the feature is deployed, exercised end to end or supported by measured results. "Missing evidence" identifies write-up or runtime material that still needs to be produced.

## Evidence gaps that need named owners

The repository currently does not prove the following items: dated competitor verification; acquisition plan; moat results; versioned prompts; model comparison; evaluation dataset and results; measured latency, cost and cache impact; security test results; logo rationale; deployed URL and hosting confirmation; analytics report; and launch or pitch materials. Assign each gap to a teammate before submission and record the responsible person and source link in the final milestones document.

The landing and onboarding implementation is on the current `codex/landing-onboarding` branch. The first confirmed-item flow is represented by `app/src/components/onboarding-flow.tsx` and `app/src/components/item-uploader.tsx`; runtime completion, saved storage and deployed behaviour still require verification.
